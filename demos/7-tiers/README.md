# tiers

BQN models of the Tiers and Algebras examples (ex35, ex37-39) plus machine-checked witnesses for the tier equivariance laws, referenced by proofs/foundations.md.

- 35-two-habitats.bqn — every row of the two-habitats table computed over an entity vector and a lattice; recurrence row modeled as shift per the decision record.
- 37-tier1-space.bqn — checkerboard spawn, scalar projection, lattice scan, figure annihilation on a conserved 8x8 ground.
- 38-tier2-records.bqn — masked aligned add, scoped fold across a statement barrier, rank scattered back to identities on tie-free gold.
- 39-tier3-opaque.bqn — matrix-view out-degrees natively; graph and behaviour-tree views as select-and-dispatch envelopes only, payloads untouched.
- t1-reverse.bqn — reverse conjugates cyclic translation (rev∘shift_t = shift_{-t}∘rev), refuting G0-equivariance as the Tier-1 legality criterion.
- t2-ties.bqn — on tied data stable ordinal rank ⍋⍋ violates Sym(I)-equivariance; dense value-only rank satisfies it.
- t2-conjugation.bqn — h = grade-inverse ∘ f ∘ grade is Sym(I)-equivariant on tie-free data, via the identity sigma_{c∘tau} = tau-inverse ∘ sigma_c; bare sort is not.
- t2-diagonal.bqn — the masked add commutes with permuting both columns diagonally, fails when gold is permuted alone.
