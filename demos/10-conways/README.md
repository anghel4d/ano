# conways

Conway's Game of Life (B3/S23) as a witness suite: what Life demands, the language already contains — a registered Moore srel (fibers shrink at the boundary, so the border is dead; a torus is a different fiber table, not a different program), the γ count over its fibers, mask algebra in a value write, and the barrier. The step is one statement; the flora act it out when the same line moves to the naru hinge. The cN names are Conway witnesses, not ano-examples.md rows.

- `c1-life-step.bqn` — one synchronous generation: the fused value write (`Planted = kin == 3 | Planted & kin == 2`) and the Kin-snapshot triple agree with the hand-stepped blinker, either order of the ± pair; the barrier is Life's double buffer, so the in-place bug cannot be written in one statement; the stencil count is asserted equal to the γ fold over the moore fibers; period 2 back to the seed.
- `c2-life-glider.bqn` — the flipbook: one statement per generation, four repetitions walk the glider one cell down-right, population pinned at 5 — a Tier-1 figure walking a conserved ground, no key minted, dropped, or moved. Performed it is one generation per statement; installed, one per tick.
- `c3-life-naru.bqn` — the rule barrier is semantics: bloom/wither under §11's shared barrier equal the fused one-rule form in either commit order; giving each rule its own barrier (bloom commits, wither re-gathers) breaks the blinker in both orders, and differently. The runnable twin installs the one-rule fused form; the emitter runs each def-rule as its own barrier (emit.c, "single rule => one barrier"), so the two-rule pair stays a .bqn witness until the shared rule barrier lands.

Two things surfaced, not resolved. First, bloom and wither both write planted: §11 admits overlapping writes only on a disjointness certificate or a merge law, and the pair's certificate is the complementary guard literals (`!Planted` / `Planted` over one pre-state) — a column-level footprint check cannot see it, so the installer must read guards, or the pair is rejected and Life needs the fused spelling. Second, the emitter's per-rule barrier versus the spec's shared rule barrier: Life is the smallest program where the difference is observable, and c3 pins the divergence.
