# compiler.md — archived anoc notes

`anoc` is the archived C predecessor of Steel. It compiled Ano to BQN and helped bootstrap the present corpus. It is not an oracle and is no longer part of the active implementation path.

Current authority is:

- `docs/ano-language.md` for denotation and surface.
- `proofs/foundations.md` for domain, lineage, effect, and habitat obligations.
- `steel/` for the reference compiler and launcher.
- `kore/` for the interactive world.
- CBQN as Steel's current execution backend, not as a language specification.

The historical machine below is intentionally omitted because it described implementation details as a surface contract and encouraged byte-for-byte agreement with C to outrank the specification. Consult Git history when that archaeology is needed.
