# Kore

Kore is the terminal editor and world viewer for Steel. The maintained operational reference is [kore/kore.md](../kore/kore.md).

Open a registry or demo, edit source or cells, execute statements, advance the staged program, and inspect query output or trace history. Registry syntax belongs to [ano-registry.md](ano-registry.md).

The current map and bitmap views use the legacy singleton lattice and positional conventions. They do not establish the nominal spatial capabilities proposed in [task 99](../todo/99-spatial-lattice.md).
