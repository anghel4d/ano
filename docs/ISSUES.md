# Ano — issues


- Identity across the barrier. A trigger payload records parent = the carrier's gather-time row while the same barrier despawns the carrier: extensional data outliving the intensional surface. Where the intensional/extensional boundary sits is the spec's Identity entry, unresolved.
- Recurrences within a statement. The cast pointer between wand blocks is a carried recurrence. Across ticks it is already expressible: the game loop is the scan, so a cursor column advanced by a standing rule works. The within-statement carry stays rejected.
- Quotation past the literal. eval splices a literal one-statement string at parse time, footprint visible to the static checks. A runtime-built string has an opaque footprint and waits on the interpreter. The analyzable middle (templates with holes, the koto nominalizer, rules writing rules) is unbuilt.
- Order-srel derivation. Deriving fibers mechanically from a declared ground order (the way moore follows from the lattice) is registry-side work not yet done.
- World-to-chunk frames. The anchored frame fills a frame's origin from the world, but the world-to-chunk (o, S) conversion itself has no surface.
- Rule ticks are frame-homogeneous. All rules sharing a tick must select in one habitat; a mixed entity-and-lattice tick (steer the bolt and burn the cell in one barrier) is rejected.
- Post-state meets the text format at its seams. Some BQN worlds have no .reg spelling, and `--save` refuses them rather than commit a file the loader rejects — nothing is written, the error names the column: an empty sym (a spawned row's default — write the sym in the spawning statement), a glyph run that is empty or carries boundary whitespace or a word-boundary `#` (despawn can produce all three), a non-finite value (`∞` from a division), a column made part-pair by a partial pair write. Two lossier seams commit anyway: stored masks — `alias` entries, `bind … mask` — are row-length data the barrier never restructures (the BQN world neither filters them on despawn nor pads on spawn), so the save reconciles them to the new n by zero-pad on growth and positional truncate on shrink purely so the dump reloads — after a despawn the kept bits can sit on the wrong rows; and a vec column despawned to n 0 re-spells as `num`, its pair-ness carried by no value; and a `-0` saves as `0` (CBQN's •Repr drops the sign inside AnoSaveNum) while `--dump` preserves it, so load∘save is identity up to the sign of zero. Whether stored masks should track structure is the same intensional/extensional boundary as the Identity entry above.
- Entity binds are positional. `bind <name> entity <k>` mirror-reads emit `((↕anoN)=k)` and `k⊑col` — a positional read, stale after a despawn. Resolve k through the key space.
- Gamma value-folds read fibers positionally in non-iota-id worlds before any despawn. The remaining case — an entity srel in a world whose id column is not the row iota, before any structural commit — still gathers positionally, because fixing it would change emitted bytes for id-carrying worlds (the strict byte-identity rule).
- Scan length meets selection width at runtime, not plan time. A scan whose scope selects a different row count than the assignment's selection crashes in AnoScat ("expected ⟨3⟩, got ⟨0⟩") instead of failing with a compile diagnostic. A plan-time width check is the fix shape.
- Guards are temp-free by convention. emitEffect's world-mode guard probe evaluates the RHS once to harvest its guard, then discards the staging buffer — the guard string survives, any temps staged under it do not. So a guard must stay a self-contained expression, and three sites require that (relGuard, the keyed hop, the chain hop); the keyed hop pays for it with a duplicated key⊐rel, once in the gather clamp and once in the guard. The structural fix is guards carrying staged deps that survive the probe discard. Until then the convention is load-bearing, not stylistic: a guard built on a staged temp emits an assignment RHS referencing a variable whose defining line the probe threw away — a miscompile.
- reg_load counts srel fibers leniently. A 3-row world with 3 `|` separators loads as 4 fibers and dies only at runtime with a BQN shape error; a load-side fiber-count check against n would turn it into a line diagnostic.
- The clock is the install runs. In the real engine `def … => …` only installs. Rules run on the clock: every installed rule, one shared barrier per tick, tick after tick. Steel has no clock, so it pretends the clock beats once at the end of each unbroken run of def lines, and each beat fires every rule installed so far. Installs persist: a rule installed early fires again at a later beat, as the engine would have it. What stays approximate is the tick count: the clock beats only where install runs sit, so a file cannot let two ticks pass without installing something new, and no rule fires again after the file's last beat.
